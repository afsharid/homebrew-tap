# afsharid/homebrew-tap

```sh
brew install afsharid/tap/passess
```

[passess](https://github.com/afsharid/passess) keeps secret values out of AI coding
agents' context: references to your password manager instead of values, exec and MCP
servers that get only what they need, redacted output, and guard hooks for seven
harnesses.

The formula installs the release binaries (macOS and Linux, arm64 and amd64) at the
checksums the release publishes. Current: `0.5.0-alpha`.
